# luna — VS Code support / VS Code 扩展

Thin shell over the luna runtime: everything editor-facing comes from the
runtime itself, never a hand-written table.

## What it does / 功能

- **Completions + hover / 补全与悬停**: from a symbol snapshot GENERATED by
  the real runtime's own introspection (`scripts/regen.sh` re-dumps it from
  `luna.introspect` + `debug.getinfo`). Require aliases (`local loop =
  require "loop"`) resolve like the runtime loads them. 补全/悬停数据全部来自
  运行时自省生成的快照，禁止手写符号表。
- **Dual-track completion / 双轨补全**: when attached, the static snapshot
  merges the target process's own completion engine — user-defined globals
  included, via the serve protocol's `\1complete` meta line. attach 后静态
  快照与目标进程实时补全合并（含用户自定义全局）。
- **Run / 运行**: `luna: Run Lua File` / `luna: Run Selection` spawn `luna`
  and stream stdout/stderr to the `luna` output channel.
- **Attach / 附加**: pick a live target from the sock dir (`luna ps` view);
  `ctrl+enter` sends the current line/selection to the attached process over
  the serve protocol — the ONLY execution channel — and the reply lands in a
  REPL document. 从 sock 目录选活进程，ctrl+enter 经 serve 协议逐行驱动。

## Coexistence / 与社区插件共存

No Lua grammar ships here — pair with a community Lua language plugin for
syntax, this extension only adds luna-specific faces. 不内置 Lua 语法，
语法交给社区 Lua 插件，本扩展只做 luna 专属能力。

## Build & test / 构建与自测

```sh
cd tools/luna-vscode
npm install
npm test        # compile + node:test; live attach tests skip honestly without build/luna
npm run package # luna-vscode-<version>.vsix
```

No marketplace: install the vsix via **Extensions: Install from VSIX…**
(`extensions.installFromVSIX`... the command palette entry). 不上市场，用
VSIX 安装。Version bumps stay manual — releases follow the repo's release
policy. 版本号由用户手动给出。

## Settings / 设置

- `luna.runtimePath` — the luna binary (absolute path or PATH name;
  default `luna`)
- `luna.attachTimeoutMs` — reply timeout for attach exchanges (default
  30000; a busy target answers at its count-hook poll points)
